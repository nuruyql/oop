# Практическая работа PR01

## Цель

Изучить управление пользователями и группами Linux, права доступа к файлам и каталогам, команды su и sudo, а также настройку Bash.

## Выполнение

Создана группа developers.

Создан пользователь student2 и добавлен в группу developers.
Основной пользователь также добавлен в группу developers.

Создан общий каталог:

/srv/shared

Владелец каталога — root, группа — developers.

Для каталога установлены права:

2775 (drwxrwsr-x)

Члены группы developers могут создавать и удалять файлы в каталоге. Остальные пользователи имеют доступ только для чтения и просмотра каталога.

От имени student2 был создан файл student2.txt.

Основной пользователь, являющийся членом группы developers, смог удалить этот файл. Это возможно потому, что удаление файла определяется правами на родительский каталог. Группа developers имеет право записи в /srv/shared.

## su и sudo

su (switch user) используется для переключения на другого пользователя и обычно требует пароль этого пользователя.

sudo позволяет выполнить отдельную команду с повышенными привилегиями. Обычно пользователь вводит свой собственный пароль, если он имеет соответствующие права sudo.

В Ubuntu вход под root по паролю по умолчанию заблокирован. Административные действия выполняются через sudo. Это уменьшает необходимость постоянно работать с максимальными привилегиями и снижает риск случайного изменения важных системных файлов.

## Настройка Bash

В ~/.bashrc были добавлены два alias:

alias ll='ls -lah'
alias cshared='cd /srv/shared'

Также была добавлена переменная окружения:

export COURSE_NAME="Operating Systems"

После открытия новой сессии Bash alias и переменная окружения работают.
